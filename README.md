# 🧮 Calculadora de Desconto

Projeto desenvolvido com HTML e JavaScript que calcula automaticamente o desconto de um produto.

Se o valor do produto for superior a **R$100,00**, é aplicado um desconto de **10%**. Caso contrário, o sistema informa que o produto não possui desconto.

## 🚀 Funcionalidades

- Inserção do valor do produto
- Cálculo automático de 10% de desconto
- Exibição do valor do desconto
- Exibição do valor final do produto
- Mensagem para produtos sem desconto

## 🛠️ Tecnologias utilizadas

- HTML5
- JavaScript

## 📚 Conceitos praticados

- Variáveis
- Funções
- Estruturas condicionais (`if` e `else`)
- Manipulação do DOM
- Eventos (`onclick`)
